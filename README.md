# Neurobet (Нейроставки) 🎾

Исследовательская платформа для прогнозирования спортивных событий и симуляции ставок с использованием машинного обучения, локальной LLM и данных о матчах и коэффициентах Fonbet.

Первый спортивный модуль платформы: **Теннис (Tennis)**.

---

## 1. Архитектурные принципы

- **Спорт #1 — Теннис**: Иерархическое состояние матча (`match` → `set` → `game` → `point`), расчет fair odds, edge и expected value.
- **Data-first & Fail-closed**: Все состояния сохраняются с точными timestamps в UTC (`TZ=UTC`). При устаревании коэффициентов или ошибках валидации ставка отклоняется.
- **ML важнее LLM**: Числовая модель рассчитывает вероятности и ценность ставок; локальная LLM выступает в роли контекстного аналитика новостей/травм.
- **Изолированный Bet Manager**: Ни ML, ни LLM не могут делать ставки напрямую. Только `bet-manager` проверяет риск-лимиты и проводит виртуальную сделку (Paper Trading).
- **Выделенная БД**: PostgreSQL с TimescaleDB в отдельном контейнере, Redis Streams для очередей событий и MinIO для сырых HTML/JSON снимков.

## 2. Структура монорепозитория

```text
neurobet/
├── AGENTS.md                  # Правила и контекст для AI-агентов
├── 01-ARCHITECTURE.md         # Главный технический документ архитектуры
├── 02-ROADMAP.md              # Пошаговый план реализации с чекбоксами
├── docker-compose.yml         # Описание контейнеров и сетей

│
├── services/                  # Автономные микросервисы
│   ├── backend/               # FastAPI REST/WebSocket API
│   ├── collector/             # Сборщик данных Fonbet (Playwright/HTTP)
│   ├── bet-manager/           # Валидатор ставок и Paper Bankroll
│   ├── neural/                # ML inference & feature extraction
│   ├── llm/                   # Локальный inference сервер
│   ├── research/              # Поиск контекста и парсинг новостей
│   ├── worker/                # Потребитель очередей Redis Streams
│   └── frontend/              # Веб-интерфейс (Next.js / TypeScript)
│
├── packages/                  # Переиспользуемые библиотеки
│   ├── contracts/             # Версионированные Pydantic схемы и JSON Schema
│   └── sports-core/           # Интерфейс SportAdapter и реестр видов спорта
│
├── sports/                    # Специфичные спортивные модули
│   └── tennis/                # Адаптер тенниса (Match Winner, live stats)
│
├── infra/                     # Скрипты инициализации инфраструктуры
│   ├── postgres/              # TimescaleDB init & migrations
│   ├── redis/                 # Конфигурация Redis Streams
│   └── minio/                 # Настройка бакетов MinIO
│
└── tests/                     # Автоматизированные тесты
    └── contract/              # Тестирование межсервисных контрактов
```

## 3. Топология портов (Хост 192.168.1.92)

| Сервис | Порт хоста | Внутренний порт | Роль |
| :--- | :--- | :--- | :--- |
| **Frontend** | `8085` | `3000` | Внешняя точка входа через Nginx Master (`/diflector/neurobet`) |
| **Backend** | `8005` | `8000` | FastAPI API |
| **PostgreSQL** | `5435` | `5432` | TimescaleDB |
| **Redis** | `6385` | `6379` | Redis Streams |
| **MinIO API** | `9005` | `9000` | S3 API сырых снимков |
| **MinIO Console** | `9006` | `9001` | Веб-консоль MinIO |

## 4. Быстрый старт

```bash
# 1. Запуск инфраструктуры (БД, Redis, MinIO)
make infra-up

# 2. Проверка статуса контейнеров
make ps

# 3. Запуск всех сервисов проекта
make up

# 4. Просмотр логов
make logs
```
