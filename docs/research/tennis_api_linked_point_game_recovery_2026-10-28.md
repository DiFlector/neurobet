Из 5,007 завершённых Fonbet-матчей предварительный поиск нашёл 131 событие с подтверждённой парой canonical identity, для которой можно проверять API-Tennis. Только одно прошло все независимые проверки идентификаторов, результата, победителя и счёта:

- API-Tennis `12170521`;
- две подтверждённые стороны совпали по canonical ID и provider alias;
- raw-источник содержит доказательства 109 point transitions и 24 game outcomes;
- история частичная, полного PBP-документа нет.

Связь добавлена новой append-only версией с сохранёнными hash/raw reference и identity evidence. Её `available_at` — `2026-10-28T04:01:46.116432Z`; исходный raw был получен `2026-10-23T12:42:29.937924Z`. Повторный apply сообщил `existing` и не создал дубликат. Проверка исторического `as_of` до времени новой версии не видит исправленную связь.

## Неразрешённые случаи

Из 131 кандидата 62 остались с неподтверждёнными или конфликтующими provider player IDs, 66 не имеют однозначного API match, один API match неоднозначен, ещё у одного не подтверждена единственная матч-связь. У 4,876 завершённых матчей нет пары подтверждённых canonical identities для такого поиска. Конфликтующие canonical cards не склеивались по имени, счёту или дате.

API raw match сохраняется как источник частичной истории. Отсутствующие очки/геймы не восстанавливались догадками. Другие потенциально неполные/безвременные метки остаются под действующими PIT-ограничениями.

## Допуск и проверка

Это повторная проверка сохранённой когорты, не полный census базы: `full_database_census=false`. Admission остаётся `blocked`; все четыре expanding validation окна и закрытый holdout не удовлетворяют порогам point/game; первые три причинных train окна имеют ноль матчей. Для всех целей оставлены пороги 500 / 4×100 / 200. Качество holdout, обучение, SHADOW и promote не запускались.

Профильные проверки в контейнере Research: 66 тестов audit/coverage/linking прошли; ещё 16 тестов point-history retrieval и существующего legacy API linking прошли. Прерывание не повлияло на состояние базы; одна подтверждённая версия связи была записана и повторно проверена на идемпотентность.
