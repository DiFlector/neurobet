# Восстановление ориентации Flashscore-связей

**Доступность новых версий:** `2026-10-27T17:38:18.903243Z`

Для сохранённых связей без ориентации использованы архивированные HTML, два подтверждённых Flashscore player ID и положение этих ID в scoreboard DOM (`home`/`away`). Порядок игроков в URL и одно совпавшее имя не использовались.

Из 88 кандидатов восстановлены 41 однозначные ориентации. Исправления добавлены новыми версиями `TennisPointMatchLink`; в evidence сохранены исходный link ID, обе identity-link версии, ID архивного документа, его raw hash и время доказательства. Старые версии не менялись, новые значения не backdate.

Остались 47 неоднозначных связей: 26 без архивного документа, 21 с несовпадением подтверждённых ID и scoreboard DOM. Они остаются исключёнными. Повторный запуск после записи не добавил дубликатов.

Источник ориентации в новых заданиях также проверен: парсер принимает сторону из двух ID в наблюдении матча или из их DOM-позиций в сохранённой странице. Если доказательства отсутствуют, связь может быть найдена, но side order остаётся неизвестным и не используется для point/game labels.
