# Предварительная проверка времени результата — 2026-10-21

## Решение

Рабочее обучение LR/GB/GRU остаётся запрещено. Это промежуточная проверка происхождения времени результата, а не новый admission report и не открытие holdout. Последний полный отчёт допуска остаётся [`tennis_label_audit_2026-10-21_streaming.json`](tennis_label_audit_2026-10-21_streaming.json), построенный в 16:17 UTC; его counts уже устарели относительно текущей БД.

## Новое доказательство

Legacy-результат может иметь более раннее время доступности, если неизменяемый Fonbet `EventStateSnapshot` уже содержит полный итоговый счёт, а упорядоченные числовые токены целиком совпадают с впоследствии проверенным официальным счётом. Используется `observed_at` этого снимка. Расписание и изменяемое `finished_at` не используются, метаданные результата не backdate-ятся.

Read-only выборка из 20 валидных числовых singles, проверенная в 16:46 UTC, дала 19 точных совпадений. Все 19 снимков были сохранены раньше дозаписи `fonbet_official_result.available_at`; диапазон их времени — 13 октября–21 октября. Подробности и примеры находятся в [`tennis_result_observation_review_2026-10-21_sample20.json`](tennis_result_observation_review_2026-10-21_sample20.json). Для точного поиска счетов проверен индексный lookup одной записи на реальном событии: `event_id` index, score-token filter, `ORDER BY observed_at, id LIMIT 1`; `EXPLAIN ANALYZE` показал index scans по двум затронутым hypertable chunks и 20.391 ms.

## Ограничение и дальнейшее действие

Полный пересчёт admission report не завершён. Варианты, которые сканировали историю широкими пачками, упирались в statement timeout на `event_state_snapshots`. Реализация переведена на ограниченный per-event `LIMIT 1` lookup, но полный run и тест актуального query helper требуют повторной проверки после восстановления временных test-container запусков. Поэтому ни новый manifest, ни новые target/window counts не выпущены.

Пока полный аудит не завершён, используются прежние достоверные цифры только как нижняя оценка: point/game/set — 31 размеченный матч всего и недостаточное число по каждому окну; match — 2,352, но temporal precedence провалена во всех четырёх validation folds. P/G/S имеют ноль подтверждённых live/observed примеров, а odds-free feature PIT остаётся несертифицированным для исторических входов. Пороги не снижались, качество holdout не открывалось, обучение не запускалось.
