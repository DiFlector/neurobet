# Восстановление времени теннисных меток и пригодных срезов

Данные зафиксированы на **28 октября 2026, 08:25:39 МСК** (`2026-10-28T05:25:39Z`). Проверена сохранённая когорта из 3,213 событий. Полный census всей базы остаётся отдельной незавершённой задачей.

## Восстановленные данные

Возобновляемый read-only проход нашёл **3,018** сохранённых снимков с точным полным финальным счётом, проверенным официальным исходом и совпадающими Fonbet UUID/native ID. Для **2,741** матча такое свидетельство доступно раньше timestamp метаданных импорта. У 277 результатов время отсутствовало в метаданных; девять из них уже имели свидетеля в прежнем индексе. Поэтому новых восстановлений неизвестного времени **268**, а остаток сократился **с 283 до 15**.

Ранее audit пропускал поиск snapshot evidence, если у результата уже было время импорта; saved-cohort режим также видел только выбранные feature snapshots. Теперь отдельный `--result-evidence-index` перечитывается по точным DB keys и сверяется с полным score и native ID. Время относится к исходному сохранённому наблюдению; `recovered_at` записано отдельно. Метаданные событий, PBP links, identity decisions и исходные snapshots не переписаны. Terminal witnesses не добавлены в признаки.

Для 50 неполных состояний проверены 126 ближайших raw-кандидатов: ни один не подтвердил прежний snapshot полностью. Найдены **шесть других** уже сохранённых полных pre-result срезов тех же событий; они выбраны с собственным временем. **44** неисправимых состояния исключены из рабочего индекса, а исходные payloads и event membership сохранены для диагностики. Рабочий индекс содержит **6,458** ключей; аудит перечитал все без пропусков.

Для оставшихся 15 недатированных результатов дополнительно проверены шесть крупнейших архивных result feeds за 16, 17 и 19 октября, включая raw event/parent IDs. Совпадений не найдено. Эта ограниченная проверка не исчерпывает весь raw archive; общий timestamp старого импорта не заменяет receipt time.

Все **14,469** примеров имеют полный числовой вектор и проходят feature PIT по действующему `tennis_odds_free_v2`, включая уже разрешённые priors/missingness. Срезов после доступности своей метки — **ноль**. Для сетов и матча выполнены размеры четырёх окон, оба класса и временной порядок train → validation. Качество holdout не рассчитывалось.

Admission остаётся **blocked**. Point/game не набирают train ≥500, каждое validation ≥100 и holdout ≥200; первые три train-окна пусты. 15 результатов без времени исключаются из причинного train. Ещё три результата позднее cutoff. Полный database census не завершён. Обучение LR/GB/GRU, holdout quality, SHADOW и promote не запускались.
