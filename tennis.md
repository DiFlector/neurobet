# Политика тенниса

Теннисные live-пороги читаются из `sports/tennis/tennis.cfg`. Там же назначены текущие production линии. Версия v4 обучается и считается в `SHADOW`; настройка назначения боевой версии для этого выпуска не меняется.

## Текущие параметры

| Параметр | Значение |
| --- | ---: |
| Минимальная вероятность | 0,62 |
| Перевес | от 0,04 до 0,07 включительно |
| Подтверждения | 3 последовательных среза |
| Первый сет | наблюдение, без записи выбранной стороны |
| Диапазон матча | 1,65 ≤ odds < 2,20 |
| Диапазон сета | 1,55 ≤ odds < 2,20 |
| Сеты, на которые разрешено ставить | сет № 2 (`stake_sets = 2`) |
| Match/set production assignment | `tennis_hist_gradient_roi_epoch tennis_v3.3.0` |

Все значения подаются из конфигурации спорта; их не следует копировать в общий код или менять ради получения большего количества решений. Фактические интервалы проверяются через `sports/tennis/src/tennis_adapter/policy.py` и `tennis.cfg`.

## Матч и сет

Первый сет остаётся наблюдательным и входит в матчевый вердикт. Начиная со второго сета, модель может выбрать сторону сета при наличии котировок и разрешённого номера сета. Матчевый выбор дополнительно учитывает закрытые сеты и подтверждённые стороны открытых сетов; при противоречивой картине выбора нет.

Сторона модели — статистическое решение, а не автоматически зарегистрированная ставка. Для `SHADOW` она пишется в `model_bet_journal`; отдельные победы и поражения матчей и сетов видны в админке. Pending и void не входят в win rate.

## Модель v4

`tennis_market_offset_boosting / tennis_v4.0.0` содержит отдельный предиктор матча и предиктор сета. Оба используют единый упорядоченный вектор из 23 признаков, завершающийся `market_is_set`. Описание формулы, обучения, временной проверки и итоговые метрики ведутся в [`NewModels.md`](NewModels.md). Старые checkpoint продолжают использовать признаки, записанные при их обучении.

## Повторная проверка

Форма исторического replay получает настройки через `GET /api/sports/tennis/policy`. Переопределение порогов действует только в этом прогоне и не меняет live-политику или обучение. ROI и win rate относятся к отдельным выборкам и должны сопровождаться числом матчей/решений.
